# Firewall Log Monitoring System 🔥

## Description
This project analyzes firewall logs using Python, SQLite, and Streamlit.

## Features
- Log storage in database
- Duplicate file prevention
- Traffic analysis (ALLOW vs DENY)
- Suspicious IP detection
- Interactive dashboard (Streamlit)

## Technologies Used
- Python
- SQLite
- Pandas
- Matplotlib
- Streamlit

## How to Run
1. Run main script:
   python main.py

2. Run dashboard:
   python -m streamlit run app.py

## Output
- Table of logs
- Bar graph visualization
- Suspicious IP detection
